# MonteCarloMinimizationParallel

# This project is a parallel version of the serial program MonteCarloMinimization

## Usage
# 1.Using the terminal/command prompt, change directory until you are in a folder where the source,bin and makefile is located
# 2. Type command "make all"
# 3. if you want to run the serial version "make runS"
# 4. if you want to run the parallel version "make runP"
